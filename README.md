# Web de GesTurno

Sitio oficial responsive de GesTurno, inspirado en el tema Guardia Civil de la aplicación.

## Contenido

- Inicio y catálogo de funciones.
- Guía completa de configuración y uso.
- Política de privacidad.
- Condiciones de uso.
- Instrucciones de eliminación de datos.
- Selector para los nueve idiomas de la aplicación.

## Uso local

Requiere Node.js 22 o posterior.

```text
npm install
npm run dev
```

La dirección local se muestra al iniciar el servidor. Para verificar la versión de producción:

```text
npm test
```

## Publicación

El sitio está preparado para el entorno Sites/Vinext incluido en el proyecto. Antes de publicar, confirma los datos del responsable legal y vuelve a revisar que la declaración de privacidad coincida con la ficha de Seguridad de los datos de Google Play y con los proveedores publicitarios activos.
